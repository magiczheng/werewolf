# 稳定性与体验优化

## 规则和权限

- 白痴翻牌后，普通放逐与 PK 都不能再次选为目标。
- 竞选发言使用稳定队列，退水不跳过下一位候选人；每位候选人最多发言一次。
- 法官模式与自动模式均限制女巫每晚只用一种药水。
- 特殊角色与白狼王最多各一位；人数上限、规则类型和警长票权在服务端校验。
- 法官面板提供明确的阶段推进按钮，法官视图默认打开法官面板。

## 房间与恢复

- SQLite 新增 `room_snapshots` 表，自动保存完整对局，包括身份、药水、投票、待处理事件、播报及请求回执。
- 进程重启后恢复房间；玩家重新登录并加入原房间即可恢复座位与身份。Map/Set 使用显式序列化。
- 单次操作及其去重回执在同一数据库事务中保存；写入失败会回滚内存状态，不广播未提交的成功结果。
- 房间离线且无操作超过 5 小时才回收；在线房间不因长时间暂停被删除。
- 同账号多端按连接统计，只有最后一条连接断开才标记离线。
- 换房先校验准入，失败保留原房间；成功切换会释放旧大厅名额。
- 对局期间保留成员与座位，不能通过退出把游戏角色删除。退出登录会使连接离线，稍后可重连。
- 大厅房主离开自动移交；房主也可主动选择在线成员移交。自动模式房主离线满 60 秒后，其他在线成员可接任。
- 法官模式开局后不转移法官权限，防止普通玩家获得全部身份，请等待原法官重连。
- 房主可确认处理离线满 60 秒的未完成操作：确认身份、不上警、弃票或空过。部分狼人离线时仍需等待队友，避免自动改变队内多数规则。
- 对局记录属于敏感数据，请与账号数据库一起备份，勿将 `data/` 放进静态目录或提交到 Git。

## 连接与账号

- 新客户端携带 `gameId`、`phaseId` 和 `actionId`；服务端拒绝旧阶段请求，重复成功请求返回原回执，重连或重启不会重复执行。
- 新协议要求操作上下文。旧客户端保留兼容入口，升级后自动使用新协议。
- 客户端离线时不发送操作，同一在途操作只发送一次。超时后先检查当前结果再重试。
- 每个受保护事件重新验证会话；注销同一令牌会立即失效其所有连接。切换账号清除旧房间绑定。
- 生产注册与登录使用异步 scrypt，并发上限为 4；同步哈希仅保留给本地种子和测试辅助。
- 限频表有容量与过期清理；建房限频按账号跨连接统计。房间容量默认 500。
- 日志使用结构化格式，不记录密码、令牌或请求正文。致命异常退出，由 supervisor 重启并恢复已提交存档。

可配置环境变量：

| 变量 | 默认值 | 用途 |
|---|---|---|
| `MAX_ROOMS` | `500` | 同时保留的房间数上限 |
| `AUTH_RATE_LIMIT` | `20` | 每 IP / 每账号每分钟认证尝试上限 |
| `TRUSTED_PROXIES` | 空 | 信任的反向代理精确 IP，逗号分隔；仅这些代理可以提供 `X-Forwarded-For` |

反向代理示例：若直接连接应用的代理地址是 `127.0.0.1`，设置 `TRUSTED_PROXIES=127.0.0.1`，并由代理覆盖转发来源头。Docker 场景应填写应用实际看到的代理 IP。

## 页面与发布

- 常用人数预设、记住上次合法配置、昵称正确传入服务端、可关闭的首次引导。
- 展示已结束投票的票型；结算后展示包括夜间行动的时间线。对局中不公开夜间行动日志。
- 对局按操作、座位、播报、法官面板分别更新；保留未变化面板的节点、选择及滚动状态。
- 大厅保留二维码和配置节点；切换房间时不会重复挂载旧视图。
- 样式分为 base/theme/roles/rooms/experience，由 `style.css` 按顺序引入；原有月夜主题保留。
- JS、CSS 与 HTML 使用网络优先策略；API 与 Socket.IO 不缓存。新版本可提示刷新，进行中的对局不会强制刷新。
- 素材与图标使用缓存加后台刷新；仅清理本应用的缓存命名空间。

## 验证

要求 Node.js 22 或以上。常规检查：

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
```

浏览器测试使用临时数据库，覆盖桌面和 390px 手机视口、九人完整第一夜、退水、投票记录、房主移交、多标签页、重复点击、离线操作及旧缓存更新。测试服务单独提高认证限频以容纳快速连续组局，不影响正式运行默认值。

CI 在常规测试之后执行浏览器测试；失败时保留截图和 trace，全部通过后才构建发布镜像。

## 布局与交互优化

- 建房页压缩首屏介绍，以常用板子、角色预览和人数为主要信息，自定义角色及进阶规则按需展开。手机端固定建房入口，12/16 人板子保持卡片内滚动。
- 大厅在手机端优先展示座位，显示入座进度、自己的座位和文字在线状态；邀请、引导及管理操作减少对座位的挤占。
- 对局增加公开阶段导航，强化等待提示、目标选择与提交中的反馈；最新播报优先展示，投票记录和复盘可折叠。
- 按钮、切换面板和弹窗使用短时过渡，遵循减少动态效果设置；确认弹窗支持焦点循环、Escape 关闭与焦点恢复。
- 浏览器回归增加配置折叠、12/16 人布局、底部按钮可见性、键盘弹窗、身份按住查看和减少动效覆盖。
